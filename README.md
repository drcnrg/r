# 🚀 ResumePro - Ultimate HD Builder

A sleek, client-side web application that generates professional, high-definition, LaTeX-style resumes directly from your browser. 

Designed with a premium UI featuring seamless light/dark modes, smooth animations, and a neon-glow synthwave aesthetic, ResumePro makes building a standout resume fast, intuitive, and visually stunning.

## ✨ Features

* **LaTeX-Style Output:** Generates A4-optimized PDFs with Academic Blue Links and the classic Computer Modern font for a highly professional look.
* **Synthwave UI / Dark Mode:** A stunning, responsive interface with soft purple and pink neon glows, animated grid backgrounds, and a seamless light/dark mode toggle.
* **Dynamic Sections:** Easily add, edit, or remove entries for Experience, Education, Projects, and Certifications on the fly.
* **Auto-Save & Validation:** Real-time auto-saving ensures you never lose your progress, with soft form validations to guide you.
* **100% Client-Side:** No databases, no sign-ups. Your personal data never leaves your browser until you hit download.
* **One-Click HD Export:** Powered by `html2pdf.js` for crisp, high-quality PDF generation.

## 🛠️ Tech Stack

* **Markup & Styling:** HTML5, Tailwind CSS (via CDN)
* **Logic & Interactions:** Vanilla JavaScript
* **PDF Engine:** html2pdf.js
* **Icons & Fonts:** FontAwesome 6, Google Fonts (Space Grotesk, Inter), Computer Modern Web Font

## 🚀 Quick Start

Since this is a purely front-end project with no build steps or backend servers required, getting started is instant:

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/yourusername/resumepro.git](https://github.com/yourusername/resumepro.git)
    ```
2.  **Open the app:**
    Navigate to the project folder and simply open `index.html` in your favorite modern web browser.
3.  **Start Building:** Fill in your details, toggle the theme to your liking, and click **Download HD PDF** when you are ready for launch.
